Language fonts

Optional. Selected TTF/OTF files are rasterized in the browser into 1-bit device .bin files at 10–18 pt.

Languages that need an uploaded font

The packer reads the uploaded font's glyph map and includes its non-ASCII glyphs. The reader's built-in fonts already cover common A–Z/ASCII characters, so upload a font for scripts such as:

  • Cyrillic
  • Greek
  • Vietnamese
  • Chinese (Simplified/Traditional)
  • Japanese
  • Korean
  • Arabic
  • Hebrew
  • Hindi and other Indic scripts
  • Thai, Khmer, and Myanmar
  • Georgian, Armenian, and Ethiopic

Optional hyphenation

Upload a hypher-generated binary trie. It is validated in the browser and copied unchanged as hyphenation.bin.
